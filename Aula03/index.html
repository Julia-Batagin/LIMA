Categorias HTML

Elementos de bloco

Ocupam toda a largura disponível da página, exemplo: <div>, <p>, <h1>, <section>, <article>.

Elementos de linha

Ocupam apenas o espaço necessário na linha. Exemplo: <a>, <span>, <strong>, <em>, <img>.

Regra Importante: Elementos de linha não devem conter Elementos de bloco.

Categorias de conteúdo

Metadata Content

São informações de configuração do arquivo HTML

<title>: Informar título da página na aba do navegador
<meta>: Definir codificação da página
<link> e <style>: Importar/Anexar CSS
<script>: Importar/Anexar códigos em javascript

Flow Content

Representa a maior parte dos elementos usados no body

<div>: Criar uma divisão genérica, agrupar "pedaços" de código.
<p>: Criar parágrafo dentro da página.
<section>: Agrupar conteúdos que partilham do mesmo assunto/idéia.
<article>: Conteúdo indenpendente e completo por si só(faz sentido sozinho).
<img>: Importar imagem, desenho ou foto(não precisa de fechamento).

Sectioning Content

Organizar grandes áreas do documento

<section>: Agrupar conteúdos que partilham do mesmo assunto/idéia.
<article>: Conteúdo indenpendente e completo por si só(faz sentido sozinho).
<aside>: Serve para guardar um conteúdo secundário/lateral (links relacionados, anúncios, biografias e etc).
<nav>: Agrupar links de navegação.

Heading Content

h1, h2, h3, h4, h5 e h6 -> Serve para adicionar títulos e subtítulos.

<hgroup>: Agrupar elementos de título.
Exemplo:

Aprenda HTML
Senai Americana

Phrasing Content

Elementos que marcam textos ou partes do texto.

<a>: Criar um link para direcionar o usuário para outra página, utilizando o atributo href.
Exemplo: Pagode
<strong>: Colocar uma parte do texto em negrito, negrito também.
<em>: Colocar uma parte do texto em itálico ou itálico também.
<mark>: Serve como marcador para o texto.
<img>: Importar imagem, desenho ou foto(não precisa de fechamento)

Embedded Content

Inserir um conteúdo externo na página

<video>: Adicionar um vídeo(pode mostrar botões de play e pause)
<canvas>: Criar uma tela em branco que poderá ser usada javascript.
<svg>: Desenhar gráficos baseados em vetores. <iframe>: Colocar um site inteiro dentro da sua página web(muito usado para vídeos e mapas).

<img>: Importar imagem, desenho ou foto(não precisa de fechamento)

Interactive Content

<button>: Criar um botão.
Exemplo: <input>: Usado para receber dados do usuário. Dentre os dados aceitos estão:
type="text": Campo de texto curto.
type="password": Oculta os caracteres digitados
type="email" ou "number": Valida dados específicos.
type="checkbox" ou "radio": Caixas de marcação e escolha única.
